Hallo, ik ben
Christian.

Ik ben 21 jaar en student Digitale Vormgeving aan PXL. Mijn passie ligt in het combineren van creatief ontwerp en technische skills — van een pixel-perfect interface in Figma tot een werkende game in Roblox Studio.

Ik werk dagelijks met tools als Figma, Illustrator, Photoshop, Canva en Blender. Op vlak van code beheers ik HTML, CSS, JavaScript en Lua.

Creativiteit, muziek en sport inspireren mij in alles wat ik doe. Ik koos voor Digitale Vormgeving omdat ik ideeën van concept tot werkende website of applicatie wil uitwerken.

Wat ik heb geleerd

Tijdens WPL2 heb ik verschillende nieuwe inzichten opgedaan. Zo heb ik geleerd om meer met grids te werken en meer aandacht te besteden aan details in mijn ontwerpen. Daarnaast heb ik ook handige tools leren gebruiken, zoals de componentenbibliotheek. Hierdoor kan ik in de toekomst sneller en efficiënter werken.

Wat ik persoonlijk als een succes zie, is dat we uiteindelijk een mooi eindresultaat hebben neergezet. Ik ben ook trots op mijn eigen bijdrage aan het project en op de manier waarop ik feedback heb verwerkt om mijn werk te verbeteren.

Verder hebben we tijdens het project regelmatig feedback gevraagd aan medestudenten, lectoren en begeleiders. Deze feedback heeft ons geholpen om verschillende onderdelen te verbeteren en verder uit te werken.

Uit mijn kernkwadranten neem ik mee dat ik mijn creativiteit als grote kracht heb, maar dat ik moet waken voor perfectionisme. Voor een volgende WPL wil ik sneller keuzes maken en efficiënter werken. Daarnaast wil ik beter leren plannen en prioriteiten stellen zodat ik mijn tijd nog efficiënter gebruik.
